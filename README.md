# InfraRabbit SDK

Client packages for the public, read-only InfraRabbit price API (https://infrarabbit.com, no key needed).

- `python/`: `pip install infrarabbit` (stdlib only, sync + async)
- `js/`: `npm install infrarabbit` (zero deps, ESM + CJS, types)
- `integrations/`: LangChain tool (Python extra `infrarabbit[langchain]`) and a Vercel AI SDK tool example

Data: InfraRabbit, infrarabbit.com. Data terms: https://infrarabbit.com/data. The MIT licence here covers the code only.
MCP server: https://infrarabbit.com/mcp
